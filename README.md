# Dr. Leitão

Projeto acadêmico da disciplina de Gerência de Projetos de Software do IFES. O Dr. Leitão é um protótipo para organização financeira pessoal, com cadastro de entradas, saídas e acompanhamento do saldo.

**Integrantes:** José Augusto Costa Breciani, Letícia da Silva Comissario, Raíssa Andrade Dutra e Samiya H. K. Andrade.
